# Polaris_TKAnimation
This is an Animation Addon for TEKKEN8 Moveset modding.<br>
It works in Blender 3.6.<br>

# Requirements
It is recommended to set Blender's Scene property as follows : <br>
<img src="https://raw.githubusercontent.com/umin135/Polaris_TKAnimation/refs/heads/main/_readme/req_0.png" /><br>

# How to use
<img src="https://raw.githubusercontent.com/umin135/Polaris_TKAnimation/refs/heads/main/_readme/how_0.png" /><br>
You can create a TEKKEN8 Dummy from the sub-menu.<br>
There are dummies that include IK and dummies that do not.<br>
